# Product Overview

This is a React-based portal application that provides a unified interface for accessing multiple websites through embedded iframes. The application features:

- Multi-site navigation with sidebar menu
- Iframe-based content display with caching
- Collapsible sidebar for better screen space utilization
- Fullscreen mode support
- Loading states and smooth transitions between sites
- Chinese language interface (zh-CN)

The portal currently integrates three sites: 影院 (Cinema), 社区 (Community), and 命理社区 (Destiny Community), all under the ssbx.site domain.
