# Technology Stack

## Core Technologies
- **React 19.2.0**: UI framework
- **React Router DOM 7.9.4**: Client-side routing
- **Vite 6.4.1**: Build tool and dev server

## Build System
Vite is used for development and production builds with fast HMR (Hot Module Replacement).

## Common Commands
```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Styling Approach
- CSS Modules for component-scoped styles (`.module.css` files)
- Global styles in `src/css/common.css`
- Organized by component and page directories

## Project Configuration
- Entry point: `src/main.jsx`
- HTML template: `index.html` (root level)
- Language: Chinese (zh-CN) as primary language
